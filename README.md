# JasonChat Discord-Like

Application de chat avancée façon Discord (Electron + Express).

## Fonctionnalités principales
- Système de serveurs et canaux (texte/vocaux)
- Fichiers attachés/téléchargement
- Appels Voix / Vidéo (structure prête)
- Threads, réactions, statuts, rôles
- Interface moderne type Discord

## Pour lancer l’application
1. `npm install`
2. `npm run dev` (pour le serveur API)
3. `npm start` (pour lancer l’interface Electron)

Front : `resources/app/wwwroot/`  
API Node.js : `server.js`
